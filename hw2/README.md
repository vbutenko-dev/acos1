# ДЗ2. Обедающие философы

**Бутенко Владислав Алексеевич, БПИ252, вариант 5.**

Каждый философ работает в отдельном POSIX-потоке: размышляет, берёт две вилки, ест и возвращает вилки. Главный поток следит за ожиданием и завершением программы. ДЗ1 с очередью событий осталось в корне репозитория.

## Сборка и запуск

Нужны компилятор C17, POSIX Threads и `make`. Команды из корня репозитория:

```sh
make -C hw2
cd hw2
./bin/philosophers-sem
./bin/philosophers-cond
```

Собираются две версии с одинаковыми параметрами:

- `philosophers-sem` — основная версия на мьютексе и семафорах;
- `philosophers-cond` — дополнительная версия на мьютексе и условных переменных.

Без параметров запускаются 5 философов, каждый ест 3 раза. Размышление длится 100–500 мс, еда — 200–400 мс. Время здесь реальное, поэтому порядок сообщений зависит от планировщика ОС. Одинаковый seed повторяет случайные длительности каждого философа, но не весь журнал, как в ДЗ1.

Быстрый запуск с короткими паузами:

```sh
./bin/philosophers-sem -n 5 -c 2 -t 5-10 -e 10-15 -w 20 -r 42
```

По умолчанию используется стратегия `ordered`: сначала берётся вилка с меньшим номером. Такой порядок исключает круговое ожидание. Стратегия `naive` берёт сначала левую вилку и может привести к взаимоблокировке. Для её демонстрации:

```sh
./bin/philosophers-cond -n 5 -c 2 -t 0 -e 1 -s naive -b
```

С `-b` в первом цикле все философы сначала получают по одной вилке и только потом пробуют взять вторую. Программа обнаружит взаимоблокировку и завершится с кодом `3`. Без `-b` результат зависит от порядка выполнения потоков.

Работа в течение трёх секунд без ограничения числа приёмов пищи:

```sh
./bin/philosophers-sem -c 0 -T 3000
```

Ctrl+C и `SIGTERM` тоже останавливают программу: ожидающие потоки просыпаются, возвращают вилки и завершаются. После этого главный поток выводит статистику.

Все события печатаются в терминал и в `philosophers-hw2.log`. Путь можно изменить через `-l FILE`. Справка доступна по `-h`; все параметры, значения по умолчанию и коды завершения описаны в [отчёте](report/REPORT.md).

## Проверка

Из папки `hw2/`:

```sh
make test
```

Для тестов нужен Python 3.9 или новее. Проверяются обе версии: работа с вилками, статистика, ожидание, сигналы, ошибки параметров и взаимоблокировка. Журналы и сводка остаются в `tests/out/`.

Последний полный запуск: **40 из 40 проверок на macOS**, **42 из 42 на Linux**. В Linux дополнительно проверяется ошибка записи в `/dev/full`.
