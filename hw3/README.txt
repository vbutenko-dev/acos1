ИДЗ №3, вариант 5. Бутенко Владислав Алексеевич, БПИ252.

Папку hw3 положить в корень репозитория acos1 рядом с hw2.
Требуется Linux, C17, make. Для проверок — Python 3.9+.

Из корня репозитория:
    make -C hw3
    make -C hw3 test
    cd hw3
    ./bin/philosophers-named
    ./bin/philosophers-unnamed

Независимые процессы, в разных терминалах из одной папки hw3:
    ./bin/table -k demo -n 3 -c 2
После сообщения «Стол готов: demo» запустить по одному:
    ./bin/philosopher demo 0
    ./bin/philosopher demo 1
    ./bin/philosopher demo 2

Справка: ./bin/table -h
Полные команды, устройство программы и результаты — report/REPORT.md.
На GitHub отчёт открывается с форматированием.
Результаты проверки в Linux: 29/29, примеры журналов — tests/results/.

Обработчики поддерживают SIGINT (Ctrl+C) и SIGTERM. Сигнал столу или
отдельному философу останавливает всех и приводит к удалению IPC.
Для параллельных независимых столов задавать разные -k и -l.
